# Features

* [Same-site published content](same-site-content.md) - opt-in flag that lets pages share the app's registrable domain.
* [Artifact short names](short-names.md) - `<name>.<content domain>` for an artifact's current version.
* [Artifact share codes](share-codes.md) - a code that opens a private artifact's current version without an account.
* [Data slots (draft)](data-slots.md) - planned: Turso-synced SQLite in the page, self-hosted tursodb behind a fork auth proxy; first used by the gym training log.
* [Data slots fallback (draft)](data-slots-fallback.md) - whole-file slot design, built only if the Turso test fails.
* [Browser session lifetime](session-lifetime.md) - `ARTIFACT_SERVER_SESSION_LIFETIME_HOURS` replaces the fixed 12-hour login.
* [Review opens in interact mode](review-interact-default.md) - HTML artifacts start in interact mode; annotate is one click away.
